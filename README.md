# E-Book Thacha v2.2

เว็บฟรีสำหรับ GitHub Pages ไม่มีฐานข้อมูล ไม่มีระบบสมาชิก ไม่มีการอัปโหลดสาธารณะ

## อัปเดต GitHub
1. เปิด repository `thacha-free-ebook` > Add file > Upload files
2. ลากไฟล์ทั้ง 6 ไฟล์จากโฟลเดอร์นี้ (ไม่ใช่ ZIP) ลงใน repository ที่ระดับ root
3. ยืนยันการแทนที่ไฟล์เดิม แล้วกด Commit changes
4. รอ GitHub Pages เผยแพร่ 1–5 นาที และกด Ctrl+F5

## เพิ่ม / ลบ / แก้หนังสือ
เปิด `books.json` แก้ข้อมูลในรายการหนังสือ (แต่ละเล่มอยู่ใน `{ ... }`)
- เพิ่ม: คัดลอกรายการตัวอย่างทั้งก้อนแล้ววางคั่นด้วย comma `,` และตั้ง `id` ไม่ซ้ำ
- ลบ: ลบรายการทั้งก้อนและ comma ที่คั่นอย่างถูกต้อง
- `title` ชื่อหนังสือ, `author` ผู้เขียน, `category` หมวดหมู่, `description` รายละเอียด
- `color` สีปก เช่น `#127d83`; `year` ปี; `isbn` ไม่บังคับ
- `license` ระบุใบอนุญาต/หลักฐานสิทธิ์ (อย่าใช้เป็นการยืนยันสิทธิ์โดยไม่มีหลักฐาน)
- `file` ใส่ URL HTTPS ของไฟล์ที่มีสิทธิ์เผยแพร่ หรือปล่อยว่างถ้ายังไม่ผ่านการตรวจ
- ตรวจ JSON ให้ถูกต้อง (ไม่มี comma เกินที่ท้ายรายการ)

## ตั้งค่าแบบฟอร์มเสนอหนังสือ
เปิด `script.js` ค้นหา `const ADMIN_EMAIL=''` แล้วใส่อีเมลผู้ดูแล เช่น `const ADMIN_EMAIL='your-address@example.com'`
แบบฟอร์มจะเปิดโปรแกรมอีเมลของผู้ใช้ ไม่ส่งข้อมูลไปยังเซิร์ฟเวอร์โดยตรง และไม่แนบไฟล์อัตโนมัติ

## ลิขสิทธิ์และการเผยแพร่
ผู้ดูแลต้องตรวจสอบหลักฐานสิทธิ์ด้วยตนเองก่อนใส่ลิงก์ดาวน์โหลด; ISBN ไม่ใช่หลักฐานสิทธิ์
ห้ามอ้างว่าหนังสือได้รับ peer review หรือใช้ขอตำแหน่งทางวิชาการได้หากไม่มีหลักฐานและการยอมรับตามเกณฑ์ที่เกี่ยวข้อง
ตรวจอีเมลติดต่อใน `policy.html` และข้อมูลนโยบายก่อนเผยแพร่จริง
