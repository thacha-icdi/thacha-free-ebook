# Thacha Free E-Book
เว็บไซต์ห้องสมุดออนไลน์แบบ Static ใช้ GitHub Pages ได้ฟรี ไม่มีฐานข้อมูลหรือระบบสมาชิก

## เปิดใช้งาน
1. สร้าง GitHub repository ใหม่ เช่น `thacha-free-ebook` (ตั้งค่า Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ root ของ repository
3. ไปที่ Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save
4. รอให้ GitHub แสดงลิงก์เว็บ ปกติรูปแบบ `https://USERNAME.github.io/thacha-free-ebook/`

## เพิ่ม/แก้/ลบหนังสือ
แก้ไฟล์ `books.json` เท่านั้น โดยแต่ละรายการประกอบด้วย `id`, `title`, `author`, `category`, `description`, `color`, `file`, `license`
- เพิ่ม: คัดลอกรายการ JSON เดิม เปลี่ยนข้อมูล และคั่นรายการด้วย comma
- ลบ: ลบ object ของหนังสือออก (ตรวจ comma ให้ถูกต้อง)
- `file`: URL แบบ https ของไฟล์หนังสือที่ตรวจสอบสิทธิ์แล้วเท่านั้น; เว้นว่างไว้เพื่อไม่ให้ดาวน์โหลด
- `color`: รหัสสี 6 หลัก เช่น `#127d83`
- `license`: เก็บข้อมูลสิทธิ์เพื่อใช้ตรวจสอบภายใน ควรเก็บหลักฐานแยกอย่างปลอดภัย
- หนังสือที่แสดงมาเป็นรายการตัวอย่าง ไม่มีไฟล์หนังสือจริง

## ก่อนเปิดใช้งานจริง
- เปลี่ยน `YOUR_EMAIL@example.com` ใน `index.html` และ `policy.html` เป็นอีเมลจริง
- ตรวจทานนโยบายให้ตรงกับวิธีเก็บข้อมูลและการดำเนินงานจริง
- ขอหลักฐานสิทธิ์ของหนังสือก่อนเพิ่ม URL ดาวน์โหลด และเก็บหลักฐานอย่างเหมาะสม
- อย่าใช้ GitHub เป็นที่เก็บไฟล์ e-Book ขนาดใหญ่หรือแจกจ่ายไฟล์ละเมิดลิขสิทธิ์
- ฟังก์ชันค้นหา/กรองทำงานบน GitHub Pages; ถ้าเปิด index.html ตรงจากเครื่อง fetch อาจถูกบล็อก
